## 🔨 编译与运行

任意章节的题目都可以用 GCC / Clang 直接编译：

```bash
# 以第 7 章第 8 题为例
cd "第07章：C控制语句：分支和跳转"
gcc test8.c -o test8
./test8
```

## 💡 代码约定

- 每个源文件**独立可编译**，不依赖其他文件
- 常量一律用 `#define` 命名（不用魔法数字）
- 提交信息格式：`Complete/Improve/Fix Ch7 ExN：<一句话说明>`
- 数值、税率、工资率等参数均来自教材原题，按需修改即可
